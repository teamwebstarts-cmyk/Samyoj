# Visual Spec: Auth Login / Signup

## Source
- Design: `ui design /image.png`
- Hero art: `client/public/brand/auth-hero.png` (girl + baked marketing overlays)
- Logo: `client/public/brand/samyoj-logo.jpeg`
- Viewport: desktop primary; mobile collapses to form + compact logo

## Goal
Sign in / create account with Samyoj branding matching the shared marketing login composition, wired to existing auth APIs.

## Layout map
1. Left (`lg+`): full-bleed hero image + logo/badge/headline overlay
2. Right: soft light column with white form card + trust badges under card
3. Mobile: form only, logo above card

## Exact copy (login)
- Welcome back 👋
- Sign in to continue to your workspace.
- Work Email / you@company.com
- Password / Enter your password
- Remember me · Forgot password?
- Sign in · or · Continue with Google
- Don't have an account? Create one free

## Signup
Same left panel; form: Create your account + existing name/company/email/password fields.

## Tokens
- Accent: WhatsApp green (`whatsapp-600` / `#25D366`)
- Card: white, ~20px radius, soft shadow
- Font: Plus Jakarta Sans (existing)
