## Responsive design overhaul (2026-08-19)

Plan: `plans/responsive_design_overhaul_4c718c2b.plan.md`. Desktop-only focus. No mobile breakpoints added.

### Phase 1 — Foundation (DONE)

**P1.1: Max-width1600px → 1440px**
- 1536px viewport (1080p at 125% OS scaling) was hitting horizontal scroll with1600px max-width.
- Changed to 1440px across all page containers (`index.css`6 instances) + FlowBuilderPage (2 instances).

**P1.2: Fluid spacing tokens**
- `--card-gap`: static1rem → `clamp(1rem, 0.938rem + 0.078vw, 1.25rem)` (scales 1280px → 1920px)
- `--card-pad`: static0.875rem → `clamp(0.875rem, 0.816rem + 0.059vw, 1.125rem)`
- `--page-gutter-x`: static2.5rem → `clamp(1.5rem, 1.422rem + 0.078vw, 2.5rem)`
- Compact density overrides also fluid.
- Appearance slider stores updated: step3 (default) removes inline override → fluid CSS takes over. User override still works for manual steps.

**P1.3: Fluid heading typography**
- `.text-display` (text-2xl): static24px → `clamp(1.375rem, 1.336rem + 0.2vw, 1.75rem)` (22px → 28px)
- `.text-title` (text-xl): static20px → `clamp(1.125rem, 1.086rem + 0.2vw, 1.5rem)` (18px → 24px)
- Rem-dominant so `data-text-size` toggle still works.
- Body text NOT fluid (research: don't fluid-scale body in CRM).

**P1.4: Fluid topbar search**
- Search pill:3 media queries (360px/400px/440px) → `clamp(320px, calc(218px + 1.05vw), 500px)`
- Single fluid rule covers all desktop widths.
