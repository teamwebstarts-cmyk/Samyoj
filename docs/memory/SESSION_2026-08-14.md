## 3. Calling “feel real” (Sarvam)

- Voice rules: 1–2 spoken sentences, Hinglish OK, **not** “5–15 words”.
- Opening = one `joinSpokenTurns(consent, greeting)` line. Default greeting: `Hi, thanks for calling. How can I help?` (saved orgs keep old greeting until reset).
- Phrase-only human/callback intercept — words like “person” / “schedule” must not steal the turn (`voice-intent.ts`).
- Full LLM reply then **one TTS clip** (`splitForTts` only if > ~450 chars). Do **not** speak every sentence as a separate HTTP TTS (that caused रुक-रुक gaps).
- TTS pace ~1.12. Prefetch next chunk while playing if split.
- **No** WebSocket TTS rewrite. **No** acoustic barge-in / AEC.

**Echo-safe listen (production harden):**

- Mute STT while `speaking` **and 400ms after** (`STT_ECHO_TAIL_MS`, `shouldMuteCallStt` in `spoken-text.ts`).
- User can interrupt **only in the gap** (`processing && !speaking`) — LLM/TTS wait, not over playback.
- Do **not** clear `speaking` on STT speech-start (old “perfect perfect” echo loop).

**Hang-up / support (tightened):**

- Human: talk to agent, real support team, किसी से बात, सपोर्ट टीम, बात करवा. **Not** generic `टीम से बात` / `support.{0,24}बात`.
- End call: hang up, end the call, कॉल काट, call रख, goodbye / bye bye. **Not** lone `bye`, **not** generic `रख दे`. Callback phrases excluded.
- `request_human` / `end_call` / `schedule_callback` tools. Live transfer **forced off** (`liveTransferEnabled: false`). Support = WhatsApp Inbox follow-up + hang up. Never promise “please hold”.

**Credits / length:** `maxCallDurationSec` default **480** (8 min). UI: Calls → Customize → Advanced.
